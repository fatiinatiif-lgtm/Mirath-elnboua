# ميراث النبوة

مشروع Flutter لمكتبة كتب دينية تعمل محليًا دون اتصال لعرض ملفات PDF.

## الموجود حاليًا
- شاشة افتتاحية مدتها 5 ثوانٍ.
- واجهة عربية RTL وألوان أصفر/نبيتي.
- الرئيسية والبحث (يفتح المكتبة) والوضع الداكن.
- أقسام المكتبة المطلوبة.
- قسم العقيدة ← المتون، وفيه ملفات PDF الثمانية المرفوعة بأسمائها الأصلية.
- قارئ PDF محلي بلا أزرار تكبير أو تصغير، مع تقليب أفقي للصفحات.

## التشغيل
1. ثبّت Flutter SDK.
2. من مجلد المشروع نفّذ:
   `flutter pub get`
3. شغّل:
   `flutter run`

## البناء
`flutter build apk --release`

## البناء من الهاتف عبر GitHub
ارفع محتويات هذا المجلد إلى مستودع GitHub، ثم افتح تبويب Actions وشغّل سير العمل `Build Android APK`. بعد نجاحه حمّل artifact باسم `mirath-nobowa-apk`.

## إضافة كتب
ضع ملفات PDF في `assets/books/`، ثم أضف كل كتاب إلى قائمة `creedBooks` أو إلى القسم المناسب في `lib/main.dart`، وأضف مجلد الأصول في `pubspec.yaml` (المجلد الحالي مشمول كاملًا).
